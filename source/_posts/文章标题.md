网络安全从零入门学习路线与学习笔记
适用人群：零基础入门、大学生、转行网安、CTF入门、想系统学习网络安全的学习者
学习目标：建立完整网安知识体系，掌握基础网络、漏洞原理、渗透思维、工具使用、合规思维
学习理念：先懂网络，再懂漏洞，再学工具，最后练实战
一、网络安全前置基础（必学）
网络安全的本质是网络 + 系统 + 代码 + 漏洞思维，基础不牢，后续渗透、CTF、漏洞挖掘全部看不懂。
1.1 计算机基础
- 了解计算机组成：CPU、内存、硬盘、进程、线程
- 理解文件系统、权限机制、程序运行原理
- 理解操作系统用户权限（普通用户/管理员/root）
1.2 网络基础（重中之重）
所有Web渗透、内网渗透、流量分析全部基于网络知识。
- OSI七层、TCP/IP五层模型
- HTTP/HTTPS协议区别、请求包、响应包、状态码
- TCP三次握手、四次挥手、UDP特点
- IP地址、子网掩码、网关、DNS解析原理
- 端口概念、常见端口：80、443、22、3306、3389
- Cookie、Session、Token 认证机制
1.3 系统基础（Linux为主）
网安从业者必备操作系统，靶机、渗透、代码调试全靠 Linux。
- Ubuntu/Kali 基础命令：文件操作、权限、进程、网络命令
- 理解 chmod、chown 权限机制
- 熟悉 ssh 远程连接、端口开放、服务启动
- 了解 Windows 基础：注册表、组策略、用户权限、共享文件
1.4 编程基础（最低要求）
不会代码只能用工具，会代码才能挖漏洞、写脚本、免杀、自动化渗透。
- Python：必学，写POC、EXP、扫描器、爬虫、批量脚本
- PHP：看懂Web源码、理解Web漏洞成因
- JavaScript：理解前端漏洞、XSS、前端绕过
二、Web安全核心学习（入门主攻方向）
Web安全是零基础最好入门、就业岗位最多、实战效果最明显的方向。
2.1 核心漏洞原理（必须吃透）
学习顺序：原理 → 复现 → 修复 → 绕过
- SQL注入：万能密码、联合查询、布尔盲注、时间盲注
- XSS跨站脚本：存储型、反射型、DOM型、Cookie窃取
- CSRF跨站请求伪造：无Token防护导致越权操作
- 文件上传漏洞：后缀绕过、MIME绕过、图片马
- 文件包含漏洞：本地包含、远程包含、伪协议
- 目录遍历：读取任意文件、源码泄露
- 弱口令/暴力破解：后台登录、端口服务爆破
- 逻辑漏洞：越权、重置密码漏洞、支付漏洞、任意登录
2.2 常用渗透工具（熟练使用）
- Burp Suite：抓包、改包、重放、爆破、漏洞扫描（Web神器）
- Nmap：端口扫描、服务探测、系统探测
- Dirsearch/FFUF：目录扫描、后台扫描、源码泄露探测
- Hydra：账号密码爆破
- Sqlmap：自动化SQL注入检测与利用
三、进阶学习方向（提升阶段）
3.1 内网渗透
Web拿到权限后，如何渗透内网、提权、横向移动、抓域控。
- Windows/Linux 提权思路
- 内网信息收集、端口扫描、存活主机探测
- 域环境基础、域渗透基础
- 横向移动、权限维持、后门持久化
3.2 CTF竞赛
适合学生党快速提升综合能力，细分方向：
- Web：漏洞利用、代码审计
- Misc：杂项、流量分析、隐写
- Crypto：密码学、加解密
- Pwn：二进制漏洞（高阶）
- Reverse：逆向工程
3.3 代码审计
看懂源码，从根源找漏洞，薪资最高的方向之一。
- PHP/Java/Python 代码审计
- 常见CMS漏洞复现与分析
- 漏洞挖掘、编写POC/EXP
四、实战平台（每天必练）
网安只看不学、只学不练=白学，必须动手复现。
- DVWA：新手入门漏洞全场景靶机
- WebGoat：官方安全训练平台
- BUUCTF：国内免费CTF刷题平台
- VulnHub：综合靶机下载实战
- 攻防世界：零基础友好刷题平台
五、安全合规与职业素养（重中之重）
网络安全红线必须牢记
- 禁止未经授权测试任何外网网站、服务器
- 禁止恶意渗透、窃取数据、挂黑页、勒索
- 所有学习测试仅限：自己靶机、自己搭建环境、授权测试项目
法律依据：《网络安全法》《刑法285/286条》
六、科学学习时间表（零基础版）
- 第1阶段（1-2周）：网络基础 + Linux基础 + Python基础
- 第2阶段（3-4周）：Web漏洞原理逐个学习 + DVWA复现
- 第3阶段（1-2月）：工具熟练使用 + 刷题 + 独立复现漏洞
- 第4阶段（长期）：代码审计、内网渗透、CTF、漏洞挖掘
七、个人学习心得
1. 网安不是“敲工具”，是思维 + 原理 + 代码。
2. 遇到不懂的不要死磕，先记录、再复盘、再复现。
3. 多写笔记、多复盘、多复现，复现一次胜过看十遍教程。
4. 保持敬畏心，技术是工具，守法是底线。
八、后续学习规划
- 搭建个人靶场环境
- 系统学习每一种漏洞的原理与修复
- 坚持刷题、复现、写博客记录学习过程
- 积累POC、EXP、工具脚本库
